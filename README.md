These are the notebooks used for the Introduction to Radio Astronomy course. 
"Final Pulsar X" and "Final Pulsar Y" notebooks show analyses of two pulsars measured with the Dwingeloo Telescope. 
"Report 2" refers to an analysis of measuring the CMB temperature using a crude horn antenna made by other students.
"Report 3" refers to an interferometry assignment where we infer the shape of the Sun using measurements made from 9 baselines.
